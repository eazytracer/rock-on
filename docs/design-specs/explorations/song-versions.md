# Exploration: Song versions

**Idea:** one song, several arrangements, e.g. acoustic, an alternate tuning, a medley cut. Think Ultimate Guitar's multiple tab versions. Users copy a version to their catalog, and when a new version appears they're asked whether to sync it.

**Questions the mockups must answer**

1. What's shared across versions (title, artist) and what's per version (tuning, key, duration, links, notes)?
2. Does a setlist item point at a specific version? (Likely yes: "acoustic set" vs "full band".)
3. How does the catalog avoid near-duplicate rows? One row with a version count, or one row per version?
4. How does "a new version exists, add or sync it to My Songs?" appear without nagging?
5. What does "New version" from the song menu start from: a copy of the current version?
6. Where do personal notes attach: to the song, or to a version?

**Fallback if versions don't work out:** linked copies. "Add to My Songs" makes a copy that follows the band version while you're a member and becomes yours when you leave.

**Must not:** make the everyday single-version song any more complicated.
