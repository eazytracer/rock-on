# Exploration: Performance mode

**Idea:** run a live show from the app, song by song, built on the practice session. It's mainly for solo and duo acoustic acts. Most bands will still tape a printed setlist to the floor, so PDF/print export matters to them more.

**Mockups should show**

1. Chords and lyrics from the song notes, readable at a distance and scrollable hands-free or with a pedal.
2. Next song plus a tuning-change warning.
3. No accidental exits; screen always on; works offline.
4. How it starts from a show (its copied set).
