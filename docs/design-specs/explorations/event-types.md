# Exploration: Event types

**Idea:** everything on the calendar is an event of a type, built from shared blocks (see `00-overview.md` → Event model). New types (open jam, tip jukebox) should be cheap to add.

**To validate with mockups**

1. Practice as an event type: does it still feel like a practice, not a generic event? (Unconfirmed; it needs mockups.)
2. Scheduled jams: the before phase (requests, volunteering, e.g. a birthday party), then **Go live** at start into the live jam.
3. One consistent create flow: pick a type, then show only that type's fields.
4. Attendance (the band, with RSVP) and Guests (outsiders who play) must look clearly different.

**Future types:** open jam (walk-up guests choose instruments, host assigns per song, end-of-night recap); tip jukebox.
