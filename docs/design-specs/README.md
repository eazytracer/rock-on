# Rock On design specs

Start with `00-overview.md`: roles, contexts, navigation, the event model, shared rules and the tuning colours.

- `workflows/`: end-to-end user journeys (01–13).
- `pages/`: one spec per screen (Purpose, Must, Must not, Roles, States, Links, Future).
- `explorations/`: open questions to mock up before deciding. These are not requirements.

Markers: **[Not built]** required but missing; **[Future]** leave room, don't build; **[Explore]** undecided.
