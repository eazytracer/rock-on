# Calendar

**Purpose:** every show, practice and event in one place.

**Must**

- **Agenda view** (the main view today): Upcoming (soonest first), then Past (most recent first).
- Filter: All / Shows / Practices / Events. Sidebar and More links can open it pre-filtered.
- Rows: date block, title, venue or location, time, type, Confirmed or Cancelled.
- **New:**
  - On All, pick the type.
  - On a filter, create that type straight away.
- Row menu: Open, **Duplicate** (shows and practices), Delete (with confirmation).
- On the Events filter: **Join with a code**.

**Must not**

- A separate shows or practices list page; the filters replace them.

**States:** empty → "Nothing on the calendar", with Book a show / Schedule practice.
