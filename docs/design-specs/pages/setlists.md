# Setlists

**Purpose:** the current context's setlists.

**Must**

- Cards: name, song count, total time, next show it's attached to (tap → show), a short song preview.
- Search; sort: name, newest, oldest, next show.
- **New setlist** → editor.
- Card menu: Duplicate, Delete (with confirmation).

**Must not**

- Statuses or status filters. Separate tabs for band and personal.

**States:** empty → what a setlist is, plus **New setlist**.

**Links:** card → setlist editor (`workflows/06`).
