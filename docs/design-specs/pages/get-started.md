# Get started

**Purpose:** a first choice for new users without a band or a link.

**Must**

- Four clear paths:
  - **Create a band:** name only.
  - **Join a band:** code or link → preview → Join.
  - **Got an event code?**
  - **Continue solo.**
- Also reachable later from the switcher, Home and More ("Create or join a band").
- Each path ends somewhere useful: Home with the walkthrough, or the event.

**Must not:** join a band without the preview; land on an empty screen.
