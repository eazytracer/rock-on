# Settings

**Purpose:** account and app preferences (`workflows/13`).

**Must**

- Sections:
  - **Profile** (link).
  - **Account:** email, sign-in methods, change password, **Delete account** [Not built].
  - **Tunings.**
  - **Notifications** [Future].
  - **Appearance:** System / Light / Dark.
  - **About:** version from the build, What's new, Help & feedback [Not built].
- Tunings:
  - List the custom ones; built-ins are read-only.
  - Create: instrument, strings, notes, name, colour.
  - Delete with confirmation; songs keep the label.

**Must not:** song display options (they live on the lists); a developer section; "clear local data".
