# Jam hub

**Purpose:** start, join or return to jams (`workflows/09`).

**Must**

- **Your jams:** live (hosting or joined, time left, code, Live badge) and upcoming scheduled jams.
- **Host a jam:** optional name, plus an optional starting setlist from your personal setlists.
- **Join with a code.**
- A short explainer: find songs you all know, then build a queue.

**States:** none active → just Host and Join.
