# Jam public view (no account)

**Purpose:** let anyone with the link follow tonight's setlist.

**Must**

- No sign-in. "Let the host know you're here": enter a name or stay anonymous; the name can be changed later.
- Live setlist, with "Live · updated Ns ago"; "Starting soon" before a scheduled jam goes live.
- Clear errors: invalid link, expired, not found.
- Prompt: **Sign up free to join** / **Log in**, returning here afterwards.
- The native app opens it if it's installed; otherwise the web.

**Must not:** require an account, or ask for more than a name.
