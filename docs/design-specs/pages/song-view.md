# Song view [Not built]

**Purpose:** look a song up: everything about it in one place, read-first.

**Must**

- Title, artist, album, tuning (colour plus name), key, BPM, duration, tags.
- **Links:** tap to open (tabs, Spotify, lyrics, video, audio, cloud file).
- **Notes, all layers clearly told apart:**
  - Band notes (shared).
  - My notes (private).
  - When opened from a setlist or practice: that item's note.

  Each can be edited in place; Markdown with formatting help.

- **Used in:** setlists and upcoming shows (catalog context).
- **Edit** button → song editor.
- The same view opens from the catalog, setlists, practices and shows, with context-relevant extras.

**Must not**

- Open in edit mode.
- Hide which notes are shared and which are private.

**Future**

- [Explore] Versions switcher (`explorations/song-versions.md`).
- [Future] The member "how do I feel" rating.
- [Explore] Chords and lyrics for performance mode.
- [Explore] How the notes layers sit in the view is open to the designer.
