# Events (jam nights)

**Purpose:** events you host or are invited to (`workflows/10`).

**Must**

- **Hosting (N)** and **Invited (N)** lists.
- Cards: name, date, venue, your RSVP, people avatars, Cancelled.
- **New event**; **Join with a code**. An invite link (`?join=CODE`) joins automatically and opens the event.
- Desktop: a split view with the selected event's detail.

**Must not:** a "Public" promise with no way to find public events.

**States:** empty → Host an event / Join with a code.

**Future:** [Future] Browse public events.
