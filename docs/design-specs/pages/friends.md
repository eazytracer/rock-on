# Friends

**Purpose:** your musician connections (`workflows/11`).

**Must**

- Your friend code: copy and QR. **Scan a QR** in the native app [Not built].
- Privacy: Discoverable by name; Who can add you (Everyone / Friends of friends / Code only).
- **Add a friend:** search by name, or enter a code.
- Lists: Requests (accept or decline), Sent, Friends (remove).

**States:** none → "No friends yet", with your code and **Add a friend**.
