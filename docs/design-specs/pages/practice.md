# Practice (view / create)

**Purpose:** plan one practice and review it afterwards. Flow: `workflows/08`.

**Must**

- Edit in place: optional title, date, time, duration, location.
- Focus notes and wrap-up notes (Markdown).
- **Songs:**
  - Add via the browser or **add all from a setlist**.
  - Reorder; a note per song.
  - Practice variant of the setlist row.
- Status worked out from the time (upcoming / in progress / done).
- **Start practice session**, prominent whenever there are songs.
- **Attendance** [Not built].

**Must not:** a manual status field.

**Roles / context:** band only.
