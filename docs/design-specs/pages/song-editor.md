# Song editor (add / edit)

**Purpose:** enter or correct a song's details (`workflows/04`).

**Must**

- Title first; Spotify suggestions appear quietly as you type, and never block manual entry.
- Fields:
  - **Title** (required).
  - Artist, album.
  - **Tuning**, with **New tuning** and **Manage tunings**.
  - **Key:** a fast picker with minors; the Circle of Fifths is preferred.
  - BPM, **duration** (m:ss), tags.
- **Reference links:** add, edit, remove inline; URL, label, type (detected automatically).
- Band context, add mode: **Also add to My Songs**.
- Explicit Save and Cancel. Cancel warns if there are unsaved changes.

**Must not**

- Require anything but the title.
- Mix notes editing into the form; notes live in the song view.
