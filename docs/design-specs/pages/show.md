# Show (view / create)

**Purpose:** everything about one gig. Flow: `workflows/07-schedule-a-show.md`.

**Must**

- Edit in place: name, date, time, venue, address, load-in, soundcheck, set length, pay, notes.
- **Confirmed** checkbox; **Cancelled** toggle (struck through, kept).
- **Contacts:** add, edit, remove; tap to call or email.
- **Set:**
  - Attach (copied in, labelled "Copied from…", re-copy option) or create new.
  - Read-only song list (show variant of the setlist row) with totals and "52 of 45 min".
  - **Edit set**; **Remove** it from the show.
- **Attendance:** who's going, maybe, or can't [Not built].
- Delete (in the menu, with confirmation).

**Must not:** extra statuses; set edits that leak into the original setlist.

**Roles / context:** band only; any member can edit.

**Future:** [Future] calendar sync and push; [Explore] performance mode.
