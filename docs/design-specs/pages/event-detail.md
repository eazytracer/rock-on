# Event detail (jam night)

**Purpose:** run or take part in one event (`workflows/10`).

**Must**

- Header: name, venue, date, start–end time (editable by the host); **Invite friends**.
- **Lineup:**
  - Songs with "added by", tuning and key.
  - Add or edit in a tray; drag to reorder (managers).
  - Guests raise or withdraw a hand per part.
- **Requests** (badge = pending):
  - Guests request a song and offer parts; managers approve or reject.
  - Shows "Requests closed" and "Auto-approve on" states.
- **People:**
  - Participants with their status.
  - Make or remove co-host (host); remove (managers); leave (yourself, not the host).
- **Access** (host): visibility, code, QR, invite link, request toggles, **Cancel event**.
- **RSVP** control for guests [Not built].

**Roles:** Host > co-hosts (managers) > guests.

**Must not:** casting UI unless casting is on (`explorations/casting.md`).
