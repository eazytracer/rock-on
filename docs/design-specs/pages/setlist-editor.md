# Setlist editor

**Purpose:** build and annotate one setlist. The full spec is `workflows/06-build-a-setlist.md`.

**Must (summary)**

- Name, editable in place. Setlist notes (Markdown). Every change saves as you make it.
- Items: songs (numbered), breaks (length plus notes), sections (titled).
- Reorder that works one-handed on a phone.
- **Setlist row:** number, title, tuning, duration, tuning-change flag, plus optional fields via view options.
- Header totals: songs, total time with breaks, tuning changes, "52 of 45 min" when attached to a show.
- Song browser: current context only, **add all from a setlist**, already-added songs marked; in a band, **From my songs**.
- Item menu: open song view, edit song, item note, remove.

**Must not:** statuses, or a second editor for personal setlists.
