# Notifications

**Purpose:** what happened while you were away, plus What's new.

**Must**

- Tabs: All / Updates (release notes) / Activity.
- **What's new** card: the latest release notes with the version (hidden on Activity).
- Feed: Recent (24h) and Earlier. Each item has an icon, title, body, relative time, and an unread dot.
- Tap → mark read and open the item.
  - If it's from another band, first ask **"Switch to ‹Band›?"**.
- Dismiss an item; **Mark all read**.
- An unread badge on the bell (header) and in the sidebar.

**States:** empty → "You're all caught up".

**Future:** [Future] push for the agreed types (see Settings → Notifications).
