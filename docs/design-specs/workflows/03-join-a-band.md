# Workflow: Join a band

**Goal:** a bandmate gets from an invite to being inside the band with one confident tap.

## Flow

1. **Receive:** an invite link (text or chat), a QR code (in person), or a typed code (Get Started, or "Create or join a band").
2. **Sign in if needed:** the invite survives sign-up (`01-sign-up-and-get-started.md`).
3. **Preview:** band name, a few member names, member count, **Join** / **Not now**.
4. **Join:** you land on Home in the band's context. The band appears in the switcher.
5. **Settle in:** a prompt to add your instruments (profile), and to bring your songs (Personal → band) if you have any.

## Must

- Messages for each failure: code not found, expired, use limit reached, already a member (in which case, switch to the band instead).
- The native apps open invite links straight into the app.
- Scanning a QR code works from inside the app [Not built] and from the phone camera.
- The owner and admins see the new member appear live.

## Must not

- Join without the preview and an explicit tap.
- Make the joiner hunt for the band afterwards.
