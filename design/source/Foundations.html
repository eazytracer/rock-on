02b · Light & dark

Same roles, two themes

Postel's LawJakob's LawLaw of Similarity

The app follows the system setting, and Settings → Appearance can override it (System / Light / Dark). Every role has a value in each theme, so screens are designed once. Dark stays the stage default: practice session, performance and jam live suggest dark when they open, and you can stay in light. Light is the daytime admin theme: building sets, booking shows.

Accents keep their fill colour in both themes, always with dark ink on top. On light, coloured text uses a deeper ink version (brand ink #b84d00, personal ink #3f49c9) to clear 4.5:1. Tuning dots use the light value of each tuning pair (§03), which clears 3:1 on the light background; the caps label next to it carries the meaning at full text contrast. In light, height comes from white surfaces plus a soft shadow, the reverse of dark.

03 · Tuning spine

A pitch spine

Law of SimilarityVon RestorffMental ModelTesler's Law

Tuning always shows its colour and its name. In rows it is a tinted pill with the label in the tuning colour (Song Row). The label carries the meaning and the dot is a quick extra cue (Von Restorff: never colour alone).

Hue follows pitch. Built-ins are ranked by their average offset from standard (semitones per string). They are then spread evenly along one path in OKLCH, so eleven tunings get about 23° of hue each. They also get brighter as they get higher: the low end is deep magenta, Standard is bright lime. Hue and lightness change together, so even neighbours differ in two ways at 8px. The path skips the brand-orange band (35°–75°) and red, which is reserved for danger. Custom tunings use the same path (§04), so one rule (Mental Model) explains every colour: darker and cooler means lower. Each tuning is a pair: the same hue, with lightness tuned per theme (dark L .64→.88, light L .45→.62), so every dot clears 3:1 as a graphic on its own background (WCAG 1.4.11). The readout under each dot shows both values and their contrast.

Known overlaps, all with a label beside them: Drop D and Standard sit near success green and warning yellow. Semantic colours always carry an icon and words.

04 · Custom tuning colour

Higher tuning, brighter colour

Tesler's LawHick's Law

A new tuning gets its colour automatically, so nobody has to pick one (Tesler's Law). The picker is there for anyone who wants it, and Reset to auto undoes the override.

sum  = Σ MIDI note of every string
ref  = Σ MIDI of standard tuning for that instrument
off  = (sum − ref) / strings  // avg semitones vs standard
t    = clamp((off + 4) / 5, 0, 1)  // −4…+1 → 0…1, same path as built-ins
hue = 345° − t × 235°  // magenta (low) → blue → cyan → lime (high)
L = 0.64 + 0.24 × t (dark) · 0.45 + 0.17 × t (light) · C = 0.16  // OKLCH, gamut-clipped

Dividing by the string count means a 4-string bass and a 7-string guitar use the same scale.

The path skips 35°–75° (shaded on the wheel), so an auto colour is never brand orange. Custom colours are the user's choice: auto is only the starting point, and any picked colour is fine because the label always names the tuning.

Try it on the phone: step a string up or down, drag on the wheel, or switch instruments. The name and colour show up straight away in a song row (Doherty Threshold). The note and stepper targets are 44pt or larger (Fitts's Law).

10 · Overlays

Three patterns, one job each

Jakob's LawHick's LawOccam's Razor

Each kind of task always opens the same way, so the app's behaviour is predictable. This replaces the five patterns the old prototypes mixed.

Full-screen route

Creating or editing anything with fields: song editor, new show, new tuning, profile. Close on the left, Save on the right. Leaving with unsaved changes asks first. Back gesture works.

Bottom sheet

Quick picks and actions: row actions (they replace kebabs), tuning picker, key picker, Move, share/QR. Swipe down to dismiss. Within thumb reach.

Dialog

Only for confirming something destructive, and it names the consequence ("Used in 2 setlists"). The destructive button is red and on the right. Typed confirmation for delete band / account / transfer.

Non-blocking feedback: toast (bottom, 4s, optional Undo) for your own actions. Banner (top, grouped, "3 changes by Mike") for bandmates' changes. Never push for live edits.
